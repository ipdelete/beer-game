AI Benchmarks & Eval Frameworks

Open-source benchmarks and evaluation frameworks. Reference material for the beer-game benchmark tool.

Benchmarks

1. LiveBench

Repo: LiveBench/LiveBench · License: Apache 2.0

Contamination-resistant benchmark; questions refresh monthly across reasoning, coding, math, data analysis, language, and instruction following. Best modern reference for fighting train-set contamination.

2. SWE-bench

Repo: SWE-bench/SWE-bench · License: MIT

Real GitHub issues from popular Python repos. Models must produce patches that pass hidden tests. Gold standard for ecological validity; Dockerized per-repo eval environments.

3. HELM

Repo: stanford-crfm/helm · License: Apache 2.0

Stanford CRFM's framework. 100+ scenarios, multi-metric (accuracy, robustness, calibration, fairness, efficiency, bias). Most comprehensive holistic eval.

4. BigCodeBench

Repo: bigcode-project/bigcodebench · License: Apache 2.0

Practical coding tasks with complex instructions and diverse function calls. Tight task spec + test harness; clear pass@k mechanics.

5. EvalPlus (HumanEval+ / MBPP+)

Repo: evalplus/evalplus · License: Apache 2.0

Enhanced HumanEval/MBPP with 80x more tests to expose flaky pass@k results. Reference for hardening existing benchmarks.

6. MMLU-Pro

Repo: TIGER-AI-Lab/MMLU-Pro · License: MIT

Harder MMLU variant — 10 answer choices, more reasoning-heavy. Shows how to refresh a saturated benchmark.

7. GAIA

Repo: huggingface.co/gaia-benchmark · License: Apache 2.0

Real-world assistant tasks requiring tools, multi-step reasoning, and web browsing. Agent-style benchmark close in spirit to strategic decision-making games.

8. AgentBench

Repo: THUDM/AgentBench · License: Apache 2.0

Multi-environment agent evaluation (OS, DB, web, games, code). Multi-environment harness pattern directly relevant to beer-game style sims.

9. τ-bench (tau-bench)

Repo: sierra-research/tau-bench · License: MIT

Tool-use and multi-turn dialog evaluation by Sierra. Multi-turn protocol design and stateful environment scoring.

10. WebArena

Repo: web-arena-x/webarena · License: Apache 2.0

Realistic web agent benchmark with self-hosted sites. Reference for fully sandboxed, deterministic environment setup.

11. OSWorld

Repo: xlang-ai/OSWorld · License: Apache 2.0

Computer-use agent benchmark across real OS apps. Heavy sandboxing, screenshot/action evaluation, trajectory scoring.

Frameworks & Harnesses

12. lm-evaluation-harness (EleutherAI)

Repo: EleutherAI/lm-evaluation-harness · License: MIT

De facto harness for MMLU, GSM8K, BBH, ARC, and 200+ other tasks. Powers the HF Open LLM Leaderboard.

13. Inspect AI (UK AISI) ⭐

Repo: UKGovernmentBEIS/inspect_ai · License: MIT

Modern eval framework. Task → Solver → Scorer abstraction; built-in sandboxing, tool use, multi-turn. Best architectural fit for the beer-game tool.

14. FastChat / MT-Bench

Repo: lm-sys/FastChat · License: Apache 2.0

LMSYS's framework; includes MT-Bench (multi-turn LLM-as-judge eval). Canonical LLM-as-judge implementation.

15. Arena-Hard-Auto

Repo: lmarena/arena-hard-auto · License: Apache 2.0

Automated Chatbot Arena proxy using strong judge models. State-of-the-art pairwise comparison patterns.

16. Aider Polyglot Benchmark

Repo: Aider-AI/aider (benchmark/) · License: Apache 2.0

Real-world coding edit tasks across multiple languages. Practical local-model benchmark.

17. OpenAI Evals

Repo: openai/evals · License: MIT

Lightweight YAML/JSON task definitions. Good for simple custom evals.

18. Promptfoo

Repo: promptfoo/promptfoo · License: MIT

Developer-first; YAML-based; strong DX patterns.

19. DeepEval

Repo: confident-ai/deepeval · License: Apache 2.0

Pytest-style assertions for LLM outputs.

Closed / No Public Repo

  • Artificial Analysis — proprietary methodology; results only.
  • OpenRouter Rankings — aggregated usage data; not a benchmark harness.
  • Chatbot Arena leaderboard — partially open via FastChat; ranking pipeline proprietary.

Suggested Study Order for the Beer-Game Tool

  1. Inspect AI — adopt the Task/Solver/Scorer pattern.
  2. LiveBench — contamination-resistance ideas (vary demand patterns).
  3. AgentBench / τ-bench — multi-environment, multi-turn agent harness patterns.
  4. SWE-bench — Docker sandboxing and deterministic env setup.
  5. HELM — holistic, multi-metric reporting.
