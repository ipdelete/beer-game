1 Lace up the cosmic shoes

Clone the repo, install the Python environment, and keep the beverage clear of the keyboard. This is the Beer Game Benchmark. It simulates Sterman's four-role supply chain and scores models by what the system actually does.

The benchmark name is Beer Game Benchmark. The game is retailer → wholesaler → distributor → factory. The enemy is the bullwhip effect.
cd ~/src/beer-game
uv sync

If that works, you are standing on the approach under ultraviolet judgment. The pins are nervous.

2 Roll a one-frame smoke test

Run the smallest mechanistic bundle first. No model server, no drama, no weird root-folder confetti, no Richard Simmons yelling over the telemetry.

uv run bench run --mode mechanistic --turns 1 --run-id smoke-mech

By default, generated bundles land here:

/tmp/beer-game-runs/smoke-mech.eval
If a CSV, PNG, or random run folder appears in the repo root, somebody rolled over the foul line.

3 Run the real config

The checked-in smoke config proves layered YAML resolution, scenario imports, model imports, and bundle writing all still tie the room together.

uv run bench run --config configs/runs/smoke.yaml --run-id config-smoke

Want to put outputs somewhere else? Say so explicitly, like an adult wearing bowling shoes and electric-pink wristbands:

uv run bench run \
  --config configs/runs/smoke.yaml \
  --runs-dir /tmp/beer-game-night \
  --run-id league-night

The repo stays clean. The rug survives.

4 Read the scorecard

Reports are plain terminal tables: tokens, latency, costs, metrics, parse strategy histograms. No velvet rope, no cloud dashboard, no guy named Chad asking you to sign in.

uv run bench report smoke-mech

Or point straight at the bundle:

uv run python -m src.bench.report /tmp/beer-game-runs/smoke-mech.eval
Total cost: lower is better.
Bullwhip: factory variance versus demand variance.
Parse success: did the model give usable orders?
Recovery: did the system calm down after the shock?

5 Bring in a model

For GABM mode, point the benchmark at an OpenAI-compatible local endpoint. Ollama is the usual house ball glowing under the blacklight.

LLM_ENDPOINT="http://localhost:11434/v1" \
LLM_MODEL="mistral:latest" \
uv run bench run --mode gabm --turns 1 --run-id smoke-gabm

The model plays each role by placing integer orders. The simulator enforces the supply chain. Nobody gets to whisper across lanes.

6 Compare two bowlers

When a bundle has paired model results across the same scenarios and epochs, compare them with bootstrap significance. Science, but with rental shoes and synth drums.

uv run bench compare /tmp/beer-game-runs/<run_id>.eval \
  --baseline model-a \
  --challenger model-b \
  --metric total_cost

Matched pairs matter. Same scenarios. Same epochs. Same demand seeds. No funny business from lane 12, even if lane 12 has a fog machine.

8 Keep the alley clean

  1. Generated bundles default to /tmp/beer-game-runs.
  2. Comparison plots default to /tmp/beer-game-comparison.
  3. Tournament scripts default to /tmp/beer-game-tournament.
  4. Do not commit generated CSVs, PNGs, caches, logs, or local model output.
  5. Small fixtures belong under docs/examples/ only when they are intentional.

/tmp means "this machine, this run, disposable." Local. Glowing. Repo-safe.
